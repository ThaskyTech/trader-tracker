# TradeTrack (working title)

A mobile-first personal trading journal and analytics dashboard, built to track 
manual and broker-synced trades, visualize performance over time, and surface 
patterns across strategies.

## Why this project
Built as a fullstack learning project to go deeper into React, real-time data 
with Socket.IO, and PostgreSQL/Prisma — while solving a real problem from my 
own day-trading activity (forex, indices, crypto).

## Tech stack
**Frontend:** React, Vite, Tailwind CSS, PWA (vite-plugin-pwa)
**Backend:** Node.js, Express, Prisma, PostgreSQL
**Auth:** JWT
**Real-time:** Socket.IO
**Testing:** Vitest, React Testing Library
**Deployment:** Vercel (frontend), Railway (backend + DB)

## Features
- [ ] Manual trade entry (instrument, direction, entry/exit price, size, P&L)
- [ ] Mobile-first dashboard: monthly P&L, win rate, calendar heatmap
- [ ] Daily trade log drill-down per calendar day
- [ ] CSV export
- [ ] Broker API sync (planned — MetaApi / Binance)
- [ ] Real-time execution feed (planned)

## Status
🚧 In active development — built as a portfolio project.
